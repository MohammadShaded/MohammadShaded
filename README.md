## Selected builds

### ExpoSee — Exhibition experience platform

A web and mobile product for exhibition organizers, vendors, and visitors. It brings together interactive indoor mapping, booth management, real-time communication, and a context-aware assistant over exhibition data.

- Multiple experiences for organizers, exhibitors, and visitors
- Indoor navigation and interactive exhibition maps
- Real-time product communication and AI-assisted discovery
- **Built with:** React, React Native, Node.js, TypeScript, PostgreSQL, Supabase, Firebase, RAG

### [TravelEase — Travel booking experience](https://github.com/MohammadShaded/Travel-Booking)

A travel and accommodation interface built around reusable components, typed contracts, predictable state, and a maintainable frontend workflow.

- Search, booking, validation, and responsive user flows
- Component documentation and automated testing
- **Built with:** React, TypeScript, TanStack Query, Zustand, Formik, Vitest, Storybook

### [Village Management System — Community data platform](https://github.com/MohammadShaded/village-management-system-Backend)

A full-stack platform for managing structured village information, demographics, users, galleries, and communication between administrators and residents.

- GraphQL APIs and role-aware authentication
- Real-time administrator and user communication
- **Built with:** React, Node.js, GraphQL, Apollo, WebSockets, MySQL, JWT

### [RentItOut — Rental platform backend](https://github.com/MohammadShaded/RentItOut)

A structured backend for rental listings and discovery, including secure access, flexible filtering, and cloud-hosted relational data.

- REST APIs, JWT authentication, and advanced query filtering
- Model-route-controller organization
- **Built with:** Node.js, Express, MySQL, AWS RDS, JWT
